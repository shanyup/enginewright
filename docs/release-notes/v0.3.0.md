# Enginewright v0.3.0 (draft release notes)

Early preview. UE 5.8, Windows (Win64) only.

## Install

Download `Enginewright-0.3.0-UE5.8-Win64.zip`, unzip it into your project's `Plugins/` folder and open the project. Client configs (Claude Code, Codex, Cursor, VS Code, Hermes) are written to `Saved/Enginewright/clients/`. See the README for the five steps.

## New since v0.2

- **UMG**: `widget_create`, `widget_tree`, `widget_get`, `widget_add` (widget, properties and slot layout in one checked call), `widget_set`, `widget_remove`, and `widget_render` (a Widget Blueprint to PNG at any resolution, no Play In Editor needed).
- **Runtime UI with CommonUI support**: `ui_state` lists what a player's screen shows (widgets in the viewport, CommonUI activatable widgets and stacks, visible buttons with label, selected state and rectangle); `ui_click` clicks by name or label and refuses a button that another widget covers; `ui_open` / `ui_close` show one screen in Play In Editor. CommonUI is used through reflection, so projects without it work too.
- **Gameplay Tags**: `gameplay_tags_list`, `gameplay_tag_add` (strict names, read back), `gameplay_tag_remove` (refused while assets use the tag).
- **Multiplayer tests on one machine**: `pie_actors` (what the server and each client see: count, net roles, owner, property values; waits for replication), `pie_net_emulation` (lag, loss, duplicates, reordering; profiles off / average / bad).
- **Measuring**: `class_measure` (size of a class or Blueprint without placing it), `screen_coverage` (how big an actor looks from a player's camera).
- **Safer rename**: `asset_rename` reports text and IDs that still name the old asset (a redirector cannot fix those); `dryRun` previews referencers and such text.

## Fixes

- The plugin builds in projects that use unity builds (helper names no longer clash).
- Adding and removing widgets keeps the Widget Blueprint's variable list consistent (no compiler ensure).

## Known limits

- Tested on UE 5.8 Win64 only.
- `ui_click` checks covering widgets at the UMG level; it does not press keys or gamepad buttons (use `pie_input`).
- One editor per port (default 3100). Set `ENGINEWRIGHT_PORT` to run several editors.
