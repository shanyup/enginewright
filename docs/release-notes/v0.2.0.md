# Enginewright v0.2.0 (draft release notes)

Early preview. UE 5.8, Windows (Win64) only.

## Install

Download `Enginewright-0.2.0-UE5.8-Win64.zip`, unzip it into your project's `Plugins/` folder and open the project. Client configs (Claude Code, Codex, Cursor, VS Code, Hermes) are written to `Saved/Enginewright/clients/`. See the README for the five steps.

## New since v0.1

- **Prebuilt plugin zip** for UE 5.8 Win64; Blueprint-only projects work without a C++ toolchain.
- **Client configs**: `client_config` and `Saved/Enginewright/clients/` for Claude Code, Codex, Cursor, VS Code and Hermes.
- **Play In Editor**: `pie_start` with 1-4 players and standalone / listen / client net mode (waits until every player has a pawn), `pie_input` for synthetic Enhanced Input actions and keys, `log_wait` for a log line.
- **Screenshots**: `screenshot` of what a player sees (or the editor viewport), `screenshot_ab` for a before/after pair with the share of changed pixels.
- **Build loop**: `live_coding_compile`, `editor_restart` (save, close, build C++, reopen), `build_status`, `automation_list`, `automation_run`.
- **Blueprints**: create, inspect, compile, variables, components, graph read, add / connect / remove nodes, pin defaults.
- **Materials**: material and material instance creation, expressions, connections, parameters.
- **Meshes and textures**: `mesh_info`, `mesh_set_material`, `texture_info`.
- **Import while the editor is open**: textures, sounds, fonts, meshes (`asset_import`, no dialogs).
- **Enhanced Input**: create actions and mapping contexts, map and unmap keys, read a context.
- **Types**: `enum_create`, `struct_create`, `type_info`.
- **Checks**: `validate` (Blueprints, data validation, broken references, map check), `id_audit`, `key_audit`, `asset_search_text`.
- **Levels**: `level_open`, `level_save`.

## Fixes

- Deleting an asset and creating it again at the same path in one editor session now works (the leftover file and in-memory object are removed).
- Renaming an asset no longer redirects a new asset created later at the old path.
- Blueprint enum variables accept the enumerator's display name as default value; an unknown name is an error with a suggestion.

## Known limits

- Tested on UE 5.8 Win64 only.
- One editor per port (default 3100). Set `ENGINEWRIGHT_PORT` to run several editors.
